# Responsive Food Ordering Interface

A modern, fast, and fully responsive front-end web application designed to simulate a real-world online food ordering and delivery system. Built with a user-centric UI, this application allows users to seamlessly explore restaurants, filter food preferences, manage their cart, and simulate checkout.

---

##  Key Features

- ** Fully Responsive Design:** Clean layout optimized for mobile, tablet, and desktop viewports.
- ** Multi-Restaurant Catalog:** Browse through popular restaurants and explore their respective menus.
- ** Veg / Non-Veg Filtering:** Easily distinguish and filter dishes based on dietary preferences.
- ** Dynamic Search Bar:** Instantly search for specific dishes or restaurants.
- ** Location Switcher:** Interactive UI element simulating location change for personalized delivery options.
- ** Single-Restaurant Cart Restriction:** Prevents cross-restaurant item mixing by strictly enforcing orders from one restaurant at a time.
- ** Interactive Shopping Cart:** Add/remove items, adjust quantities, and view real-time price calculations.
- ** Simulated Checkout:** Step-by-step interactive payment popup and instant order confirmation feedback.

---

##  Tech Stack

- **Front-End:** HTML5, CSS3, JavaScript (ES6+)
- **Styling & Layout:** CSS Grid & Flexbox
- **Icons & Assets:** Unsplash / FontAwesome (for high-resolution dish images and UI icons)
